# VM1 login style

The VM1 service login uses the approved compact brand style. Existing authentication, CSRF, sessions and legacy accounts remain in effect. Changed maintained files: server/public, server/web.py and src/shared/style.css. The deployed VM1 version and verification/rollback procedure are documented in `server-admin/docs/login-style-rollout-20261028.md`. For VM1-native authentication, see `server-admin/docs/unified-auth-policy.md`; styling does not enable shared browser sessions.
